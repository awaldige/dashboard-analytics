# 📊 Dashboard Analytics

**Dashboard interativo para visualização e análise de indicadores, desenvolvido com HTML5, CSS3 e JavaScript.**

O Dashboard Analytics é um projeto de front-end desenvolvido para demonstrar a construção de uma interface administrativa moderna, com indicadores de desempenho, gráficos dinâmicos e ferramentas de análise de dados simulados.

O projeto apresenta recursos de visualização de informações, atualização dinâmica dos componentes e adaptação para diferentes tamanhos de tela.

## ✨ Funcionalidades

- 📈 Indicadores de desempenho (KPIs).
- 📊 Gráficos dinâmicos desenvolvidos com Chart.js.
- 📅 Filtros de visualização por período: 6, 12 e 24 meses.
- 📋 Tabela de atividades recentes.
- 🌙 Alternância entre tema claro e escuro.
- 📱 Interface responsiva para desktops, tablets e dispositivos móveis.
- ⚡ Atualização dinâmica dos indicadores e gráficos sem recarregar a página.
- 📉 Visualização de receita, vendas, clientes e indicadores de desempenho.
- 🧮 Cálculos e distribuição de dados demonstrativos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript (Vanilla):** lógica, cálculos, manipulação do DOM e interatividade.
- **Chart.js:** criação e atualização dos gráficos.
- **SVG:** desenvolvimento do favicon personalizado.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/awaldige/dashboard-analytics.git
```

### 2. Entre na pasta

```bash
cd dashboard-analytics
```

### 3. Abra o projeto

Abra o arquivo `index.html` diretamente no navegador.

Não é necessário instalar dependências ou configurar um backend para executar esta versão do projeto.

A biblioteca Chart.js é carregada por CDN, portanto é necessária uma conexão com a internet para a renderização dos gráficos.

## 📊 Dados demonstrativos

O dashboard utiliza dados exclusivamente simulados, organizados em séries mensais para demonstrar o funcionamento dos indicadores, gráficos e filtros.

**Importante:** o projeto possui finalidade demonstrativa e não realiza consultas a bancos de dados ou APIs externas.

Praticar e demonstrar conhecimentos em desenvolvimento front-end, manipulação do DOM, JavaScript, visualização de dados, criação de gráficos e construção de interfaces administrativas responsivas.
